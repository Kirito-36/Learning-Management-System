# LMS User Manual - Head of Department

## 1. Sign in
Use the account created by the administrator. The Head of Department menu includes the standard lecturer functions plus moderation and release functions.

## 2. Available functions
The Head of Department can use:
- **1. My courses** — view courses assigned to the account.
- **2. My assignments** — view assignments for those courses.
- **3. Create assignment** — create an assignment.
- **4. Grant student extension** — grant an extension with a reason.
- **5. View submissions for assignment** — inspect submissions and their statuses.
- **6. Mark submission** — enter a raw mark and feedback.
- **7. Review pending marks** — approve a mark or request changes.
- **8. Release approved marks** — release an approved mark to the student.
- **9. View audit history** — search audit history by entity type and ID.
- **0. Log out** — return to the sign-in screen.

## 3. Moderate marks
1. Choose option 7.
2. Review the list of marks awaiting moderation.
3. Enter the mark ID.
4. Choose **1. Approve** or **2. Request changes**.
5. Enter a comment. A comment is required when requesting changes.
6. The system records the moderation decision.

## 4. Release marks
1. Choose option 8.
2. Review the list of approved marks.
3. Enter the mark ID to release.
4. The system confirms that the mark has been released to the student.

Only release marks after completing the required moderation checks. Use the audit history when a decision needs to be traced.

## 5. Sign out
Choose option 0. Keep account credentials confidential.
