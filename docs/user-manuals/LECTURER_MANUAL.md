# LMS User Manual - Lecturer

## 1. Sign in
Enter the username and password provided by the school administrator. The Lecturer menu appears after successful sign-in.

## 2. Lecturer menu

| Option | Function |
|---|---|
| 1. My courses | Display courses assigned to you. |
| 2. My assignments | Display assignments for your courses. |
| 3. Create assignment | Create an assignment for one of your courses. |
| 4. Grant individual extension | Set an extended due date for one student and provide a reason. |
| 5. Grant whole-class extension | Set one later due date for every actively enrolled student in the assignment's course. |
| 6. View submissions for assignment | Display submissions for an assignment, including attempt and status. |
| 7. Mark submission | Enter a raw mark and feedback; the mark is sent for moderation. |
| 10. View audit history | Search audit history by entity type and ID. |
| 0. Log out | Return to the sign-in screen. |

## 3. Create an assignment
1. Choose option 3.
2. Select a course from your assigned courses.
3. Enter the assignment title and description.
4. Enter the due date/time using `YYYY-MM-DD HH:MM`.
5. Enter the maximum mark and maximum number of attempts (1–10).
6. Confirm that the system displays the new assignment ID.

## 4. Grant an individual extension
1. Choose option 4.
2. Select the assignment ID and enter the student's user ID.
3. Enter the new due date/time and a reason.
4. The new deadline must be later than the student's current effective deadline.

## 5. Grant a whole-class extension
1. Choose option 5.
2. Select the assignment ID.
3. Enter the new due date/time and a reason.
4. The system applies the same deadline to every actively enrolled student in that course.
5. The new deadline must be later than every enrolled student's current effective deadline. If it would shorten an existing individual extension, the operation is rejected without partial changes.
6. The system confirms how many students received the extension.

## 6. View and mark submissions
1. Choose option 5 and enter the assignment ID to view submissions.
2. Note the submission ID that needs marking.
3. Choose option 6 and enter the assignment ID.
4. Select the submission ID, enter the raw mark and provide feedback.
5. If changing an existing mark, enter the reason when prompted.
6. The mark is saved for moderation; it is not immediately released to the student.

## 7. Sign out
Choose option 0. Protect your login credentials and only access courses assigned to you.
