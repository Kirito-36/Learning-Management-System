# LMS User Manual - Administrator

## 1. Sign in
Run the LMS application and enter your username and password. On the very first launch, follow the prompts to create the initial administrator account.

## 2. Administrator menu

| Option | Function |
|---|---|
| 1. List users | Display registered users and their roles/status. |
| 2. Create user | Create a Student, Lecturer, Head of Department or Administrator account. |
| 3. Activate/deactivate user | Change whether a user account is active. |
| 4. List departments | Display departments and assigned heads. |
| 5. Create department | Add a department. |
| 6. List courses | Display available courses. |
| 7. Create course | Add a course code, title, academic year and department. |
| 8. Assign lecturer to course | Link a lecturer to a course. |
| 9. Enrol student | Enrol a student in a course. |
| 10. View audit history | Search the audit history by entity type and ID. |
| 0. Log out | Return to the sign-in screen. |

## 3. Recommended setup order
1. Create departments.
2. Create Head of Department and Lecturer accounts, assigning each to a department.
3. Create Student accounts.
4. Create courses under the correct departments.
5. Assign lecturers to courses.
6. Enrol students in courses.

When creating a user, enter the requested username, full name and initial password (at least 8 characters). Students require a student number. Lecturers and Heads of Department require a staff number and department ID.

## 4. Audit history
Choose option 10, enter the entity type (for example `user`, `course`, `assignment` or `mark`) and its ID. The system displays matching audit events.

## 5. Sign out
Choose option 0 from the menu to log out. Do not share administrator credentials.
