# LMS User Manual - Student

## 1. Sign in
Enter the username and password supplied by the school. The Student menu appears after successful sign-in.

## 2. Student menu

| Option | Function |
|---|---|
| 1. My courses | View courses in which you are enrolled. |
| 2. View assignments | View assignments, descriptions, effective due dates (including any extensions), maximum marks and attempt limits. |
| 3. Submit/resubmit work | Submit work for an assignment using a file path. |
| 4. My submissions | View your previous submissions, attempts and statuses. |
| 5. Released results | View marks and feedback that have been released. |
| 0. Log out | Return to the sign-in screen. |

## 3. View assignments
Choose option 2. Read the assignment description, due date/time, maximum mark and allowed number of attempts. The due date displayed includes any individual or whole-class extension granted to you. Contact your lecturer if assignment information appears incorrect.

## 4. Submit or resubmit work
1. Save your completed work in a location accessible to the computer running the LMS.
2. Choose option 3.
3. Enter the assignment ID.
4. Enter the full path to your submission file when prompted.
5. Check the confirmation message, which displays the submission ID and attempt number.
6. If the system reports that the submission is late, check the displayed effective deadline and contact your lecturer if you believe an extension should apply.

The LMS records the file path; it does not provide a web upload page. Do not move or rename the file after submitting unless instructed by your lecturer.

## 5. Check submissions and results
- Choose option 4 to view your submission history and status.
- Choose option 5 to view results and feedback after marks have been released.
- A mark that is still awaiting moderation will not appear as a released result.

## 6. Sign out
Choose option 0. Keep your password private and submit your own work.
